What I've Built

Academic Projects

01
Hardware · Logic Design
Automated Parking Gate System
Description
Designed and prototyped a functional parking gate system using fundamental logic gates (AND, OR, NOT), demonstrating real-world automation through hardware logic.
Methodology
Utilised IR sensors to detect vehicle presence, processed signals through a logic circuit to trigger a motor-driven gate mechanism — no microcontrollers required.
Outcome
Successfully demonstrated an automated entry/exit sequence, emphasising efficiency and hardware logic. Ranked in the top percentile at the First Year Innovation Challenge.
02
Python · Data Analysis
Exploratory Data Analysis on Public Datasets
Description
A Python-based project focusing on cleaning and visualising trends within open-source datasets (weather and retail data).
Methodology
Used Pandas for data manipulation and Matplotlib/Seaborn for visual storytelling — transforming raw numbers into insight-rich narratives.
Outcome
Identified key patterns and correlations, delivering actionable insights through a comprehensive digital dashboard.
